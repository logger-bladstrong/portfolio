New founding

// Author: Zirui Zhang
// Category: Strategy
// Status: Solved

Traditional programming is like teaching a computer to follow a recipe: "Add sugar, stir, bake." You define every rule explicitly.

Machine Learning (ML), however, is different. It's like giving the computer a thousand photos of cakes and asking it to figure out what a cake looks like on its own. It's not about explicit rules; it's about patterns.

The Paradigm Shift

When I wrote my first "Hello World" in Python, I felt like a commander giving orders. But when I ran my first Linear Regression model, I felt like a gardener planting seeds and watching them grow.

# A simple glimpse into Scikit-learn

from sklearn.linear_model import LinearRegression
import numpy as np

# Data: Hours studied vs. Score
X = np.array([[1], [2], [3], [4]])
y = np.array([10, 20, 30, 40])

model = LinearRegression()
model.fit(X, y)

print(model.predict([[5]])) # Output: [50.]

The magic happens in the .fit() function. The machine "learned" the relationship between X and y without me writing y = 10 * x.

This is just the beginning. From Supervised Learning to Neural Networks, the path ahead is foggy but fascinating.

AERO-ENGINE PREDICTIVE MAINTENANCE

Research Report on Aero-engine Predictive Maintenance

Based on Physical Intuition and Neural Learning

Nuohu Li • Qiuyu Wang • Zirui Zhang April 29, 2026

ABSTRACT

This project studies predictive maintenance for turbofan engines using the NASA C-MAPSS FD001 degradation dataset. The central goal is not only to classify whether an engine is entering a high-risk failure window, but also to explain why the model reaches that warning decision.

NASA C-MAPSS LSTM Attention Random Forest Asymmetric Loss

MODEL COMPARISON

Model Precision Recall F1 AUC
Random Forest + Slope 0.88–0.90 0.74 0.80–0.81 ≈ 0.997
MLP Neural Fallback 0.80 0.82 0.81 ≈ 0.996

The Random Forest achieves excellent overall discrimination with high precision, while the MLP fallback improves high-risk recall — critical for safety-critical maintenance decisions.

METHODOLOGY

01
Data Preprocessing
Variance diagnostics, correlation analysis, PCA visualization
02
Feature Engineering
30-cycle sliding windows, local slope features, micro-fault injection
03
Model Training
Random Forest baseline + Attention-LSTM with asymmetric focal loss
04
Risk Evaluation
Recall-priority threshold selection, physical interpretability analysis

KEY INSIGHTS

⚠

Asymmetric Risk

A missed fault is much worse than an unnecessary warning. The model uses γ_fn = 10, γ_fp = 1 to prioritize recall.

🔬

Physical Intuition

Sensor correlation patterns reveal directional degradation: positive in sensors 11/4/15/17, negative in 12/7/21/20.

🧠

Neural Attention

Attention weights identify which time steps influence warnings — recent abnormal signals get higher weights.
